# 이재엽 커리어 로드맵

정보컴퓨터보안학과 재학 중인 이재엽의 커리어 로드맵. IT 기획 · 업무 분석 · 설계를 목표로(게임 · 교육 · 데이터는 도메인), 그동안의 경험(방송부 총괄 PD, 경상롤드컵 진행 PD, 웹 포트폴리오, 해군 복무, 유튜브·인스타그램 콘텐츠 운영, my-setup-proj)을 직무 역량과 연결해 정리했다.
